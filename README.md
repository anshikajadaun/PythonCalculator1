# 🧮 Python Calculator

A simple and user-friendly **Calculator application built using Python**. This project performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

## 📌 Project Overview

The Python Calculator is a beginner-friendly, console-based project designed to practice fundamental Python programming concepts.

The user can enter two numbers, select an operation, and get the calculated result.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🔢 User input for numbers
* ⚠️ Division-by-zero handling
* 📋 Simple menu-driven interface
* 🔄 Perform multiple calculations

## 🛠️ Technologies Used

* **Python 3**
* Variables
* Functions
* Conditional Statements
* Loops
* User Input
* Arithmetic Operators
